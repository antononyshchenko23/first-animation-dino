🦖 Blender 3D Animation: Walking Dinosaur Rig

This repository features an animated 3D dinosaur project created in **Blender**, showcasing custom skeletal rigging, weight painting, and a cyclic quadruped walking animation.

---

## 🎬 Project Overview

- **Model & Rig**: Detailed dinosaur mesh driven by a custom armature (`FemaleGorgo`), featuring hierarchical bone chains for the spine, neck, head, and tail.


- **Animation**: A seamless **10-second forward walking cycle (240 frames at 24 fps)**. The motion incorporates diagonal limb coordination, natural center-of-mass shifting, and secondary dynamic balancing across the tail and spine.


- **Rendering**: Configured for consistent viewport playback and final rendering.

---

## 📂 Repository Contents

- `dino.blend` — The complete Blender project file containing the rigged mesh, animation data, lighting, and camera setup.



---

## 🚀 How to Use

1. Open `dino.blend` in **Blender 4.x / 5.x**.


2. Press **Space** to play the 10-second walking animation in the viewport.
